# Architecture Decision Records (ADR)

An ADR is a short record of one architectural decision: what was decided, why, and what follows from it. Records are not rewritten after the fact. When a decision changes, write a new ADR and mark the old one as `Superseded by ADR-XXXX`.

## Adding one

1. Copy [`0000-template.md`](0000-template.md) to `NNNN-short-title.md` with the next number.
2. Fill in the sections and add a row to the table below.
